# 白话改写规则（学生版专用）

> 目标读者：学生本人（小学高年级至高中），刚考完、想把错的地方弄明白；措辞深浅按学段调整，学段越低越口语。
> 一句话原则：**先说人话，再给式子；语言降难度，数学不降精度。**

## 一、总原则

1. 用第一人称「我」叙述错误，用「你／先别急」引导正确做法；不写「该生」「本报告认为」。
2. 一句话不超过约 30 字；一段不超过 3 句；先给结论，再给理由。
3. 术语第一次出现必须紧跟一句大白话解释，之后才可用简称。
4. 每道题只解决一个问题：我到底在哪一步走岔了。不展开与本错因无关的知识。
5. 通俗 ≠ 少写步骤。正确思路的每一步、每个式子、每次舍根都要在。

## 二、术语 → 大白话对照表

| 专业说法 | 学生版写法 |
|---|---|
| 相似三角形对应顶点／对应边 | 找「双胞胎三角形」：长得一样只是大小不同；先认清谁的胳膊配谁的胳膊 |
| 判别式为完全平方数 | 根号里那个数得能开得尽，不然两根就不是整数 |
| 韦达定理 | 两根相加、相乘跟系数之间的两个固定关系 |
| 整数性约束收口 | 题目说「都是整数」，就能把范围一下卡死 |
| 分段函数 | 一个式子管不了全程，得分几段各算各的 |
| 割补法 | 用「整个减去没进来的那一块」比硬算快 |
| 临界时刻 | 形状变脸的那几秒，先拍照 |
| 分母有理化 | 把分母里的根号弄掉 |
| 新定义题 | 题目造的新词只是老知识换了个马甲，先翻译成人话 |
| 黄金矩形 | 短边÷长边 ≈ 0.618 的长方形才算 |
| 比例后项 | 先问「比的是部分比部分，还是部分比整体」 |
| 辅助线 | 补一条线，把不会的图形变成学过的图形 |
| 采分点／步骤分 | 写一步是一分，空着最亏 |
| 表达规范 | 每步写「因为…所以…」，别让老师猜 |
| 变式训练 | 换个数、换个条件、换个情境，再做一遍 |
| 艾宾浩斯排期 | 第 1、2、4、7、15、30 天各回头做一次 |
| 概念混淆 | 把「一般图形」当成了「特殊图形」，或公式张冠李戴 |
| 根的取舍 | 解出来的数要回头看落在哪一段，不在就扔掉 |
| 结构性结论 | 直接说「这次主要不是算错，是路子选错」 |

## 三、句式模板（可直接套）

- **一句话说清我错在哪**：`我把 A 当成了 B，其实……` / `算出 X 之后我没辙了，就猜……，可图里根本没有……` / `答案蒙对了，可我在同一道题里既说……又说……，自己打自己嘴巴。`
- **口诀**：一句短句 + 一个动作，例如「会动的题先拍照，一段一段算」「看到 a:b 先停一秒：一共是 a+b 份」「新词先翻译成人话；乘几就乘几，别乘两遍」。
- **类比库**：双胞胎三角形（相似）、给运动拍照（动态）、定义当尺子（概念判定）、歪地基上盖楼（前一问错导致后一问无效）、剪纸推一推（面积变化）、把过程压到 4 行（表达规范）。
- **岔路口标记**：固定的 `【就岔在这一步】`，只标在真正开始走错的那一行，不标在后续连带错误的每一行。
- **5 分钟练法**：`5 分钟小练：<动作>，练的是 <能力>`，动作必须具体到「拿纸剪」「只圈不算」「只写最后一步」。

## 四、五类错因的学生说法

| 类 | 学生版说法 | 典型开场 |
|---|---|---|
| A | 概念没搞清 | 「公式、定义只是眼熟，没真会用」 |
| B | 看错题 | 「把 1:4 看成 1:4 的另一半，漏了条件」 |
| C | 方法不会 | 「路子一开始就选错了，越算越远」 |
| D | 算错 | 「思路对，抄错数、乘错系数」 |
| E | 写不清 | 「答案对但过程打架、跳步、空着」 |

复合错因按主次写，例如「C 方法不会（主）：不会建分段面积模型；B 审题（次）：没画关键位置图」。

## 五、每题固定小节顺序（不得调换）

1. 这题在考啥（一句大白话）
2. 题目（黑字，原文）
3. 我写的（深蓝）
4. 正确答案／老师改的（红）
5. 一句话说清我错在哪（红字加粗，最醒目）
6. 两条路摆在一起看（三列对照表：第几步／我当时怎么想的／正确该怎么想的）
7. 记一句口诀
8. 错因归类
9. 换个数，再来两道（只给题目）
10. 课本知识点
11. 怎么练最快（一个 5 分钟动作）

变式答案统一放文末「对答案（做完再看）」，禁止写在题目旁边。

## 六、禁用清单

- 禁止专业黑话不解释：如「收口」「对应顶点」「判别式完全平方数」「结构性结论」「模型识别」。
- 禁止长定语从句、被动句、书面连接词（「综上」「由此可见」「值得注意的是」）。
- 禁止 emoji、装饰符号、网络梗。
- 禁止出现姓名、班级、学号、学校、考号、座位号。
- 禁止用「粗心」「不认真」代替具体错因；必须说清是哪一步、什么动作错了。
- 禁止把「不会做」写成结论；要写成「卡在第几步，下一步该找什么」。
- 禁止暗示学生能力不行；只评价动作与步骤。

## 七、准确性底线（最重要）

1. 白话改写只作用于**讲解**，题干与学生作答必须原文照抄。
2. 每题正确解法先独立验算再写；举例验证每个可能值；不确定的写进存疑清单，不猜。
3. 类比不能改变数学关系：说「双胞胎」可以，但对应边顺序不能说反。
4. 数值、根号、分数、舍根理由与家长版必须完全一致；两份文档互相校对一次。
5. 每题正文控制在约 600–900 字，对照表 4–6 行；超长说明拆解方式没抓住重点，回去重写口诀。
