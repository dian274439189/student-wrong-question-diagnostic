# 标准答案交叉论证（ACV · L2.0 层 · v2.0 / 2026-11-12）

> 目的：把「标准答案」从单点判断升级为**多路独立求解 + 红队反证 + 收敛裁决**，使答案正确率尽可能逼近 100%。
> 位置：L1.5 题面审查通过 → **L2.0 交叉论证** → L2 四维判定 → L3 确认层。
> 归属：属「判准」阶段第一步，替代旧版「独立算标准答案」单条规则。

## 0. 目标与边界（先说清楚）

- **可量化目标**：`答案收敛率 = CONFIRMED 且 confidence=high 的题数 ÷ 计入统计题数`；标准档目标 ≥ 90%，精审档目标 ≥ 95%。
- **不承诺 100%**：多路论证能压低随机错误，无法消除同源错误与模型能力边界。凡未收敛，一律上报交人工裁定，**禁止用多数票强行定案**。
- **残余风险（必须向用户明示）**：
  1. 六路共用同一个错误前提（同源错误）；
  2. 超纲／竞赛题超出模型可靠推理范围；
  3. 官方答案本身错误且无第三方证据可交叉；
  4. 主观题（语文／英语／证明）本无唯一解；
  5. 题干转写错误导致所有路径基于错误输入求解。
- **因此设计原则是「不可收敛即上报」，不是「尽量给一个答案」。** 用剔除存疑题换来的高正确率没有意义。

## 一、六路独立求解（多角度）

**工程要求（关键）**：

- 六路**分次独立执行**，每路只给「题干 + 条件 + 该路指定方法」，**不提供其他路的结论、不提供官方答案**（R5 除外）；
- 禁止在同一段提示里一次性输出六路；那只会得到同一结论的六次复述；
- 每路固定输出：`结果 / 关键步骤 / 自检结论 / 存疑点`；
- 全部完成后，单独做一次**裁决轮**，此时才可以看到六路结果。

| 路 | 视角 | 具体方法 | 主要拦截 |
|---|---|---|---|
| R1 | 正向直接解 | 按定义／公式／定理从条件推到结论 | 基本概念误用 |
| R2 | 逆向代入验算 | 把候选答案代回原题，逐条检查条件、根是否舍、范围、单位、整数性、图形位置 | 增根、漏根、范围错 |
| R3 | 换方法复算 | 换一条**独立**解法路径：几何↔代数、解析↔作图、能量↔牛顿定律、公式法↔配方法、特例↔通式 | 同一路径内的同错 |
| R4 | 边界／特例／量纲 | 极限值、退化情形、量纲分析、数量级、正负号、图形存在性、对称性 | 形式合理但物理／几何上不可能 |
| R5 | 答案源比对 | 官方答案 PDF、红笔订正、教材例题、教师批改；**只作交叉核对，不作唯一依据** | 卷面答案与独立解冲突 |
| R6 | 红队反证 | 专门尝试推翻 R1–R5 的共识：构造反例、找漏解、检查是否存在更完整表述（尤其 E 类表达规范） | 共识性错误、表述不全 |

**降级规则**：

- 标准档至少跑 **R1、R2、R3、R6** 四路；R4、R5 有材料就跑，无则标注「未执行：原因」。
- 精审档六路全跑；缺任一路须在 `answer_verification[].routes` 写明缺哪路与原因。
- 快速档跳过 ACV，且**不得输出正确率结论**。
- 语文／英语主观题、证明题：不启用数值收敛，改用「采分点清单 + 教材原话 + 题干限定词」三对照；仍无标准答案 → 标「需人工提供答案」，不得自判（沿用 L2 原条款）。

## 二、收敛裁决规则

| 情形 | 结论 | 置信度 | 处置 |
|---|---|---|---|
| ≥ 4 路结果一致，R6 未推翻，且机器验证（如有）通过 | `CONFIRMED` | `high`（有机器验证或人工裁定）／`medium`（仅逻辑收敛、无机器验证，如几何／证明／主观题） | 写入 `right`，正常判定 |
| 任一路径出现分歧 | `CONTESTED` | `pending` | **禁止多数票定案**；逐路列出差异点，定位第一个分歧步骤；写入 `doubts_answer`；交 L3 人工裁定；不计入正确率分母 |
| R6 构造出反例／发现漏解多解 | 回退 L1.5 | `pending` | 先重审题面，可能是题目问题而非答案问题 |
| 无 R5 外部答案源 | 不降级 | 不变 | 标注「无答案源可依」；只要 R1–R4 + R6 收敛即可 `CONFIRMED`（修正旧口径「AI 独立复核，无红批可依」的弱表述） |
| 自建模型与官方答案冲突 | `CONTESTED` | `pending` | **并列两套解法，不预设「参考答案对、我算错」**；取消旧「先查自建模型」的单向先验；标「待裁定」请用户／老师确认 |
| 官方答案确认有误（答案册印错） | 以独立论证结果为准 | `high`（须人工确认后） | 家长版写明「官方答案第 X 题有误，本题按独立复核结果判定」；写进 `doubts_answer`；请老师确认 |

> 历史案例中曾出现化学答案册单题印错——该场景是本层的主要设计动机之一。

## 三、机器验证门禁

1. 凡能写成算术／比较表达式的题，必须为 `right` 写出 `verification` 表达式，并跑 `scripts/verify_answers.py` 求值与交叉门禁（答案数值须出现在表达式中）。
2. 验证不通过 → 该题不得标 `high`，强制降为 `pending`，写入 `doubts_answer`。
3. 无法机械验证的题（几何辨认、证明、语文／英语主观题）→ 必须完成 R3 换方法复算 + R6 红队，并在判定表标注「无机器验证」；不得静默放行。
4. 标准档与精审档均执行本门禁；快速档可跳过（已声明降级）。
5. `scripts/build_books.py` 会把新字段纳入脚本自检：状态值合法性、`INVALID` 题不得进错题列表、`pending` 题不得计入正确率分母、正确率算术自洽。任一失败退出码 1。

## 四、统一正确率口径（v2.0 起全流水线唯一口径）

```
计入统计题数 = 总题数
             − INVALID（题目出错）
             − SUSPECT 未裁定（题面存疑）
             − CONTESTED 未裁定（答案分歧）
             − 识别存疑／需重拍
正确率     = 判定为「对」的题数 ÷ 计入统计题数
覆盖率     = 计入统计题数 ÷ 总题数
答案收敛率 = CONFIRMED 且 high 的题数 ÷ 计入统计题数
```

**强制规则**：

1. **正确率与覆盖率必须同时报**。只报正确率、不报覆盖率，等于用剔除存疑题美化指标，禁止。
2. **输出门槛**：答案收敛率 < 90% 或覆盖率 < 80% → 不得向外输出「本次正确率 xx%」，只能输出判定表 + 存疑清单，正确率栏写「待裁定，样本不足不予计算」。
3. **待裁定题既不计入分子也不计入分母**；裁定后整体重算，不得事后手工回填进旧结论。
4. 「答案对但过程可疑」在正确率中计为「对」，但**不计入「已掌握」**并在备注标注；若属看过答案／非限时，按 L5 记「辅助正确」，单独列示。
5. 下游任何以「已掌握题数 ÷ 知识点题数」计算的指标实为掌握率，**须改称「知识点掌握率」**，不得与本节正确率混用；变式练习环节的「本次正确率」按本节口径重算。

## 五、产物字段（详见 `数据契约.md` v1.1 可选字段）

- 每题写入 `answer_verification[]`：`no / routes / consensus / confidence / machine_verified / divergence / verdict_note`
- 卷级写入 `accuracy_summary`：`total / counted / correct / excluded{...} / accuracy / coverage / convergence / gate`
- 题面结论写入 `question_audit[]`：`no / status / dimensions / perspectives / evidence / suggestion`
- 分歧与答案源问题写入 `doubts_answer[]`；题面问题写入 `doubts_question[]`
- 学生版提示写入 `student_question_notice[]`

## 六、与 L3 确认层的衔接

L3 六列表升级为**八列**：

`题号 | 学科 | 我的答案 | 正确答案 | 题面状态 | 答案收敛 | 判定 | 存疑点`

表后**四张存疑清单**：识别存疑、判定存疑、**题面存疑**、**答案源存疑**。
用户回「确认入库」前，所有 `pending` / `SUSPECT` / `INVALID` 项必须逐条得到处置意见。
