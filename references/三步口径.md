# 三步口径：先看清 → 再判准 → 最后讲得对

> 顺序是硬约束。手写认错，后面所有判定和讲解都会失真；判定不准，讲解越漂亮越有害。
> v2.0（2026-11-12）：「题面审查」嵌入第一步，「答案交叉论证」嵌入第二步，三步名称与顺序不变。

## 第一步：解决「看不清」

### 1. 先判层，再识别

- 色彩统计优先：统计每页红像素占比。灰度／二值扫描件红像素占比约 0 → 红层写「（无）」，判定层注明「AI 独立复核，无红批可依」，不要写成「需人工提供答案」。
- 三色归属：印刷原题 `#000000`、学生手写 `#003399`、教师批改／红字答案 `#C00000`、本报告标注 `#E67E22`。
- 若学生用红笔订正，会出现「红批层里混着学生笔迹」，结合语义与位置复核，标「笔色存疑」。

### 2. 图像预处理的固定动作

| 情况 | 动作 |
|---|---|
| 竖幅照片实为横放双页 | 同时导出顺时针／逆时针两版缩略图，目测确认哪版文字正立，再裁切 |
| 整页图 | 只用来定版面坐标；认字一律按题裁切，块约 1100×500 px，放大 3–5 倍 |
| 两页并排 | 先按 x 中点切页，再按栏／题切块；栏间留 40 px 重叠 |
| 答案 PDF | 即使有文字层也渲染 2.2 倍图片逐页读；公式在文字层几乎必乱码 |
| 多图同一会话 | 裁块另存新文件再读，避免图像去重导致读不到第二张 |
| 手写分数被切掉分子 | 向上扩 60–100 px 重裁，禁止按上下文反推补字 |
| 涂改／反光／倾斜 | 标【已划掉】【识别存疑：原因】或「需重拍」，不硬读 |

### 3. 易错认字点（逐项复核）

易混字符 3/C、2/3、5/6、0/O、根号内数字、上下标；几何字母 C 常被写成尖角；手写「27」的 7 带长斜尾，容易被读成单个「2」或勾。

**自洽校验**：板块红色得分用「满分 − 每题分值 × 错题数」反算。例如选择题满分 30、每题 3 分，红色分数 27 应对应恰好 1 题错；若逐题判出 2 题错，必须回头复核填涂。

**填涂区判读**：2B 涂黑的方块会替换掉 `[A][B][C][D]` 中某一项的字母标签。数清该行还剩哪几个字母，缺失的那个即所涂选项；不要把黑块右边那个字母当成答案。

### 4. 收尾

- 按原文转写，错别字标【原文如此】，看不清标 `【识别存疑：原因】`，涂改标【已划掉】。禁止编造。
- **进入第二步前先过 L1.5 题面有效性审查**：确认转写出来的题本身成立（六维 × 五视角，见 `题面有效性审查.md`）。题目出错（`INVALID`）或题面存疑（`SUSPECT`）的题，不得进入判准阶段，也不得计入正确率分母；`INVALID` 题须在家长版、学生版、八列判定表三处同时提示。
- 禁止把 OCR 误差判成题目出错：任何 `SUSPECT` / `INVALID` 都要回原图裁切块复核一次（D6 / P5）。
- 把本次新出现的误识别模式追加到 `references/识别经验库.md`（同类只记一条并更新次数）。

## 第二步：解决「判得准」

1. **先建标准答案基准（v2.0 升级为 L2.0 交叉论证）**：六路独立求解——R1 正向 / R2 逆向代入 / R3 换方法 / R4 边界·量纲 / R5 答案源 / R6 红队反证；**分次执行、互不见结论**，最后单独裁决。≥ 4 路一致且 R6 未推翻才标 `CONFIRMED`。官方答案 PDF 只作交叉核对，不作唯一依据；冲突时并列两套解法标「待裁定」，**不预设参考答案正确**。详见 `答案交叉论证.md`。
2. **四维判定，缺一不可**：答案（对／错）、方法（正确／错误／无法判断）、条件（完整／遗漏／无法判断）、表达（完整／有问题／无法判断）。客观题的「表达」写「无法判断（客观题无过程）」，不要留空。未收敛（`CONTESTED` / `pending`）的题不进四维判定，直接转第三步前的确认层。
3. **答案对但过程可疑单列**：结论对而依据错、跳步、涂改重写、疑似蒙对——不入错题库，单列提醒项；正确率中计「对」，但不计「已掌握」。
4. **复合错因拆开标注**：主因 + 次因，例如「C 方法·步骤（主）＋ B 审题失误（次）」。
5. **五类错因唯一口径**：A 概念缺失／混淆、B 审题失误、C 方法·步骤、D 计算·操作、E 表达·规范。E 类不得并入「习惯问题」。
6. **四张存疑清单必交**：识别存疑、判定存疑、题面存疑、答案源存疑，逐条写原因；不静默带过。
7. **确认层**：出八列判定表（题号／学科／我的答案／正确答案／题面状态／答案收敛／判定／存疑点）后停下等「确认入库」。用户明确要一次性完整成果时，保留判定表与存疑清单，跳过入库，把确认放到交付之后。
8. **隐私铁律**：产物不得出现姓名、班级、学号、学校、考号、座位号；家长版写「该生」，学生版写「我」。
9. **正确率口径（v2.0 全流水线唯一）**：`计入统计题数 = 总题数 − INVALID − SUSPECT 未裁定 − CONTESTED 未裁定 − 识别存疑／需重拍`；`正确率 = 判对题数 ÷ 计入统计题数`。**覆盖率与答案收敛率必须同时给出**；收敛率 < 90% 或覆盖率 < 80% 时不得输出正确率，只写「待裁定，样本不足不予计算」。待裁定题既不计分子也不计分母，裁定后整体重算。

## 第三步：解决「讲得对」

1. **复用 L2.0 收敛答案再写讲解**：动态题自建分段函数验证关键值；新定义题举例验证每个可能值；几何题核对线段和差与图形位置；应用题检验取舍条件。凡与收敛答案不一致，回退 L2.0 重新裁决，**不得另起炉灶给新答案，也不得照抄官方答案**。
2. **组织双栏对照**：把「我当时怎么想的」与「正确该怎么想」按步骤一一对齐，走岔的那行标红并加「【就岔在这一步】」。学生版只写这一步走岔了什么，家长版补完整推导与采分点。
3. **每题配齐**：一句话错在哪 → 对照表 → 口诀 → 错因 → 变式 2–3 道（自带答案）→ 知识点 → 5 分钟可执行的提升动作。
4. **全局补三张表**：知识点分布、20 分钟训练动作、1/2/4/7/15/30 天复习排期。
5. **双份输出**：按 `references/数据契约.md` 组装 JSON，跑 `scripts/build_books.py`，得到家长版＋学生版两份 Word。v1.1 可选核验字段写入后，家长版自动增加「三·补、题面有效性与答案交叉论证」章节，学生版开头自动增加题目印错提示。
6. **自检**：三色 run 级审计、隐私扫描、**v2.0 核验字段自检**、验收清单逐条打勾；未 PASS 不交付。

## 为什么是这个顺序（写给下一个实例）

- 「看不清」阶段多花一刻钟，能避免「判得准」阶段整题误判；红色分数自洽校验就是专门用来兜住这类错误的。
- 「判得准」阶段把「答案对但过程可疑」单列，是为了不把 E 类表达失分伪装成「已掌握」。
- 「讲得对」阶段先验算再写，是为了避免「讲解本身算错」——这比学生原来的错误更有害。
- v2.0 把「审题」嵌进看清、「交叉论证」嵌进判准，是因为：**题目本身不成立时判对错毫无意义，标准答案错时讲解越漂亮越有害**。两处都不是新增主线，而是让原有三步更可靠。
