# 数据契约：templates/*.json 字段定义

> 模板在 `scripts/build_books.py`，卷子数据在 `templates/*.json`。
> **换一套卷子只替换 JSON，不改渲染代码。** 已验收的示例卷数据：`templates/sample-exam.json`。
> **v1.1（2026-11-12）**：新增六个可选核验字段，全部向后兼容；v1.0 数据不填也能正常出双份 Word。

## 顶层结构

| 键 | 类型 | 必填 | 用途 |
|---|---|---|---|
| `schema_version` | string | 是 | 当前 `1.0`；含 v1.1 核验字段时可写 `1.1`，脚本不校验版本，按字段是否存在判定 |
| `meta` | object | 是 | 卷子元信息，见下表 |
| `score_rows` | array[array] | 是 | 家长版「卷面得分概览」，每行 6 列：板块／题号／满分／得分／失分／失分题 |
| `reminders` | array[[label, text]] | 是 | 「答案对但过程可疑」提醒项；可为空数组 |
| `knowledge_rows` | array[array] | 是 | 家长版知识点分布，每行 4 列 |
| `improve_rows` | array[array] | 是 | 家长版提升优先级，每行 5 列 |
| `parent_review_tasks` | array[[int, str]] | 是 | 家长版排期：`[D+天数, 任务]`，天数取 1/2/4/7/15/30 |
| `doubts_recognition` | array[str] | 是 | 识别存疑清单，逐条写原因 |
| `doubts_judgement` | array[str] | 是 | 判定存疑清单，逐条写原因 |
| `cause_rows` | array[array] | 是 | 学生版五类错因表，每行 4 列 |
| `student_knowledge_rows` | array[array] | 是 | 学生版知识块表，每行 4 列 |
| `drill_rows` | array[array] | 是 | 学生版 20 分钟训练表，每行 4 列 |
| `student_review_tasks` | array[[int, str]] | 是 | 学生版打卡任务 |
| `closing_lines` | array[str] | 是 | 学生版「几句实在话」 |
| `student_doubts` | array[str] | 是 | 学生版存疑，用学生能懂的话 |
| `parent_items` | array[object] | 是 | 家长版逐题数据，字段见下 |
| `student_items` | array[object] | 是 | 学生版逐题数据，字段见下 |

`parent_items` 与 `student_items` **必须一一对应同一批错题**，顺序一致、题号一致。

## v1.1 可选核验字段（v2.0 / 2026-11-12 起）

> **全部为可选**。字段缺失时 `build_books.py` 跳过对应章节与自检，v1.0 黄金样例保持 PASS。
> 一旦写入 `question_audit` 或 `answer_verification`，脚本启用 v2.0 自检，任一不通过退出码 1。

| 键 | 类型 | 内容 |
|---|---|---|
| `question_audit` | array[object] | L1.5 题面审查结果，字段见下 |
| `answer_verification` | array[object] | L2.0 答案交叉论证摘要，字段见下 |
| `accuracy_summary` | object | 卷级正确率／覆盖率／收敛率，字段见下 |
| `doubts_question` | array[str] | 题面存疑清单（第三张） |
| `doubts_answer` | array[str] | 答案源存疑清单（第四张） |
| `student_question_notice` | array[str] | 学生版「哪几道题可能印错了」大白话提示，一句一题 |

**`question_audit[]` 每题 6 字段**

| 键 | 类型 | 内容 |
|---|---|---|
| `no` | str | 题号，与 `parent_items[].no` 的题号可对应 |
| `status` | str | 三选一：`VALID` / `SUSPECT` / `INVALID` |
| `dimensions` | str | D1–D6 六维结论摘要，红灯维须点名 |
| `perspectives` | str | P1–P5 五视角结论摘要；未执行的视角须写原因 |
| `evidence` | str | 判定证据（条件矛盾、多解、单位冲突、原图复核结果等） |
| `suggestion` | str | 修正建议与处置说明；`INVALID` 必写「不计入正确率、不作为该生错题」 |

**`answer_verification[]` 每题 7 字段**

| 键 | 类型 | 内容 |
|---|---|---|
| `no` | str | 题号 |
| `routes` | str | R1–R6 各路执行与结果；缺路须写明缺哪路与原因 |
| `consensus` | str | 三选一：`CONFIRMED` / `CONTESTED` / `PENDING` |
| `confidence` | str | 三选一：`high` / `medium` / `pending` |
| `machine_verified` | bool | 是否通过 `verify_answers.py`；无法机械验证写 `false` 并在 `routes` 注明「无机器验证」 |
| `divergence` | str | 分歧点或「无」；`CONTESTED` 必写第一个分歧步骤 |
| `verdict_note` | str | 裁决说明；冲突时并列两套解法并标「待裁定」 |

**`accuracy_summary` 卷级 8 字段**

| 键 | 类型 | 内容 |
|---|---|---|
| `total` | int | 总题数 |
| `counted` | int | 计入统计题数 |
| `correct` | int | 判定为「对」的题数 |
| `excluded` | object | 剔除项计数，键为 `invalid` / `suspect` / `contested` / `recognition`，值为题数 |
| `accuracy` | str | 如 `86%`；未达门槛写「待裁定，样本不足不予计算」 |
| `coverage` | str | 如 `88%` |
| `convergence` | str | 答案收敛率，如 `86%` |
| `gate` | str | `PASS`（可输出正确率）或 `HOLD`（只输出判定表＋存疑清单） |

**算术硬约束（脚本强制校验）**

```
counted = total − sum(excluded.values())
```

- `INVALID` 题号**不得**出现在 `parent_items` / `student_items`。
- `consensus=CONTESTED` 或 `confidence=pending` 的题，`counted` 必须已将其剔除。
- `gate=PASS` 时三项百分比必须齐全，缺一即 FAIL。

## meta 字段

| 键 | 示例 | 用途 |
|---|---|---|
| `exam` | `数学 · 学情诊断示例卷` | 两份 Word 的标题与文件名主体 |
| `subject` / `grade` | `数学` / `通用示例` | 元信息 |
| `date` | `2026-01-01` | 生成日期，也是复习排期的起算日（`YYYY-MM-DD`） |
| `full_score` / `score` / `lost` | `120` / `92` / `28` | 学生版封面与家长版结论 |
| `wrong_count` | `7` | 学生版封面「几道失分题」 |
| `source` | `6 张照片 + 答案 PDF` | 家长版依据说明 |
| `privacy_note` | 固定句 | 家长版隐私声明 |

## parent_items 每题 12 字段

| 键 | 类型 | 内容 |
|---|---|---|
| `no` | str | `第 10 题（选择题 · 3 分）`；含小问写 `第 20 题第 (3) 问（…）` |
| `topic` | str | 考点短语 |
| `stem` | str | 印刷题干原文 |
| `mine` | str | 学生作答（含涂改说明） |
| `right` | str | 正确答案／红笔订正；**v2.0 起须与 L2.0 收敛答案一致** |
| `score` | str | `0 / 3` 这类卷面得分 |
| `where` | str | 一句话错在哪（家长版口径） |
| `four` | str | 四维判定，格式 `答案：错｜方法：错误｜条件：遗漏｜表达：无法判断` |
| `cause` | str | 五类错因，含主次；字母后必须跟空格，便于自动提取简写 |
| `steps` | array[str] | 正确思路与步骤，5–9 步 |
| `variants` | array[[q, a]] | 变式题与答案，2–3 道 |
| `points` | str | 对应知识点 |

## student_items 每题 13 字段

| 键 | 类型 | 内容 |
|---|---|---|
| `no` / `tag` / `score` | str | 题号、题型标签、得分 |
| `what` | str | 这题在考啥（大白话一句） |
| `stem` | str | 题干原文（与家长版一致） |
| `mine` / `right` | str | 我写的／正确答案（与家长版数值一致） |
| `oneline` | str | 一句话说清我错在哪（红字加粗） |
| `rows` | array[[step, mine, right, bool]] | 双栏对照；第 4 项为 `true` 时标「【就岔在这一步】」并着红色 |
| `kou` | str | 口诀 |
| `cause` | str | 错因的学生说法，仍要含 A–E 字母 |
| `variants` | array[[q, a]] | 变式题与答案 |
| `point` | str | 课本知识点（大白话） |
| `drill` | str | 一个 5 分钟可执行动作 |

## 自动生成的部分（不要写进 JSON）

- 家长版判定总表：由 `parent_items` 的 `no/mine/right/score/four/cause` 自动生成；`four` 会被压成简写，`cause` 会提取 A–E 字母。
- 学生版「一眼看懂」总表：由 `student_items` 自动生成。
- 两份文档的变式答案区：由各自的 `variants` 自动生成。
- 复习日期：由 `meta.date` 加 D+ 天数计算，不手写日期。
- v1.1 核验章节：由 `question_audit` / `answer_verification` / `accuracy_summary` 自动渲染；字段缺失则整章跳过。

## 常见错误

1. `cause` 写成 `A+B 概念…` 而没有在字母后留空格 → 简写提取失败，判定表错因列会退化成截断文本。
2. `rows` 第 4 项漏写或写成字符串 `"true"` → 岔路口标记不显示。
3. `variants` 答案写成空字符串 → 文末答案区缺项。
4. 两份 items 题号顺序不一致 → 家长版与学生版对不上，复核困难。
5. `meta.date` 用非 `YYYY-MM-DD` 格式 → 排期日期计算报错。
6. 把汇总表硬编码进渲染脚本 → 换卷时旧数据残留，违反模板／数据分离。
7. JSON 里混入姓名、班级、考号 → 隐私扫描会命中，脚本退出码 1。
8. `question_audit[].status` 写成中文或小写 → 状态值非法，v2.0 自检 FAIL。
9. `INVALID` 题仍写进 `parent_items` / `student_items` → 题目出错被当成学生错题，自检 FAIL。
10. `accuracy_summary.counted` 与 `total − excluded` 不相等 → 算术不自洽，自检 FAIL。
11. 只填 `accuracy` 不填 `coverage` / `convergence` → 指标口径不完整，交付验收不通过。
12. `CONTESTED` 的题标了 `high` 或未从 `counted` 剔除 → 未收敛却计入正确率，自检 FAIL。
