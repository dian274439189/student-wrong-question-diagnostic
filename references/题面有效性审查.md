# 题面有效性审查（QVA · L1.5 层 · v2.0 / 2026-11-12）

> 目的：在判对错之前，先确认「这道题本身是不是一道能做的题」。
> 位置：L1 识别完成 → **L1.5 题面有效性审查** → L2.0 答案交叉论证 → L2 四维判定。
> 归属：属「看清」阶段的延伸。题面不成立时，后续所有判定、错因与正确率统计都失去意义。
> 核心原则：**题目错了 ≠ 学生错了**。发现题目出错只提示并给出修正建议，绝不改写题干、绝不把该题记为学生错题。

## 一、何时必须跑

| 档位 | QVA 要求 |
|---|---|
| 快速档 | 跳过；但产物顶部必须写明「本版未做题面有效性审查与答案交叉论证，不得据此计算正确率」 |
| 标准档（默认） | 六维逐题快审；任一维亮红灯 → 强制进入五视角交叉论证 |
| 精审档 | 六维 + 五视角全开，每题给出书面结论 |
| 学生白话档 | 同标准档；学生版只呈现「哪几道题可能印错了」的大白话提示 |

批量纪律沿用主线：每批 3–5 题，出表停下等确认。

## 二、六维审查（多维度）

| # | 维度 | 检查项 | 典型红灯 |
|---|---|---|---|
| D1 | 语义完备 | 主谓宾完整；限定词（不／最／至少／恰好／分别）清晰；指代明确；无歧义句 | 「求它的值」未指明「它」；选非题写成选是题 |
| D2 | 条件充分 | 求解所需条件齐备；图示标注与文字互补而非互相替代 | 求面积却未给高；几何题只说「如图」而图不清 |
| D3 | 条件自洽 | 数值／单位／量纲一致；图形存在性；数据可实现；条件互不矛盾 | 三角形两边之和小于第三边；速度 m/s 与时间 min 混用未换算；给出互相冲突的角与边 |
| D4 | 答案可判定 | 有唯一确定解或明确解集；开放题有评分维度；无未声明的多解 | 方程两解却只留一空且未给范围；「写出一个即可」漏写 |
| D5 | 学科规范 | 术语、符号、单位对准用户填写的教材版本；不超纲、不偏怪；实验装置与原理一致 | 用超纲公式考低学段；化学「现象」与「结论」混写；物理额定值突破量程 |
| D6 | 识别 fidelity | 可疑字是否来自 OCR／裁切／反光／连笔；上下标、根号、分数线是否完整 | 把「至少」识成「最仁」；把 √5−1 识成 √5−l |

> **D6 是防误判闸门**：任何 `SUSPECT` / `INVALID` 结论，都必须回到该题原生分辨率裁切块复核一次。
> 若确认为识别误差 → 降级为「识别存疑」，按 L1 口径标【识别存疑】或「需重拍」，**不得判为题目出错**。

## 三、五视角交叉论证（多角度）

**工程要求（决定这套机制是否真的有效）**：

- 五路**分次独立执行**，每路只喂「题干 + 条件 + 学科背景」，**不喂其他路的结论**；
- 一次性在同一段提示里让模型「从五个角度各说一遍」会退化为同义复读，视为**未执行**；
- 每路固定输出三段：`结论 / 依据 / 发现的问题`；
- 全部完成后，单独做一次**汇总裁决**，裁决轮才可以看到全部五路结果。

| 视角 | 任务 | 推翻信号 |
|---|---|---|
| P1 正向求解 | 按条件直接解一遍，看能否得到确定结果 | 解不出、解出多个、解依赖未给条件 |
| P2 命题人视角 | 判断考什么考点、干扰项如何设置、预期解法是否唯一 | 干扰项本身也成立；考点超纲；选项无正确项 |
| P3 挑错反证（红队） | 主动构造反例、找第二个满足条件的解、代入边界值 | 反例构造成功 ⇒ 题目有问题 |
| P4 教材／考纲视角 | 与教材原话、公式、量纲、用户填写的当地考纲范围比对 | 术语或公式与教材冲突；超纲偏怪 |
| P5 原图复核 | 回看该题原生分辨率裁切块，确认可疑处不是识别误差 | 原图与转写不一致 ⇒ 回退 L1，不判题面问题 |

## 四、结论三态（必须显式写入产物）

| 状态 | 判定条件 | 处置 |
|---|---|---|
| `VALID` 题目成立 | 六维无红灯，五视角无异议 | 正常进入 L2.0 |
| `SUSPECT` 题面存疑 | 有歧义／条件不足／疑似印错，但存在合理补全解释 | 标【题面存疑】；列出 2 种解释及各自对应答案；**暂不计入正确率分母**；写入 `doubts_question`；请用户／老师裁定；可按最常见解释给临时答案，但必须标注「待裁定」 |
| `INVALID` 题目出错 | 明确无解／多解未声明／条件矛盾／单位冲突／图形不存在／选项无正确项 | **停止判该题对错**；标【题目有误】＋证据＋建议修正方式；从正确率分母剔除；**不得进错题库、不得出变式、不得写入 `parent_items` / `student_items`**；双份 Word 显著提示 |

## 五、提示文案模板

家长版（写进 `question_audit[].evidence` / `suggestion`）：

> 【题目有误】第 X 题：题干给出 AB=3、AC=4、BC=8，与三角形三边关系矛盾，图形不存在，无法确定答案。建议核对原题数值；本题不计入本次正确率，也不作为该生错题。

学生版（大白话，写进 `student_question_notice[]`）：

> 第 X 题卷子自己可能印错了（条件对不上），这道题先不算你错，等老师确认再说。

## 六、铁律

1. 禁止把识别误差当题目错误（D6 / P5 强制复核）。
2. 禁止自行改题、补条件、替命题人圆场；只提示与建议修正（沿用硬性边界第 3 条）。
3. 禁止把 `INVALID` 题记为「答案错」或计入失分；不得据此生成变式与复习排期。
4. `INVALID` / `SUSPECT` 必须在**家长版、学生版、L3 判定表**三处同时可见，不得只写在存疑清单里。
5. 与 L2.0 双向闭环：答案交叉论证若发现「漏解／多解／条件不足」，必须回退本层重审题面，不得直接判学生错。
6. 卷级结论必须报 `VALID / SUSPECT / INVALID` 三项计数，不能只报「无问题」。
