# 学生错题诊断助手

技术标识：`new-cuoti-pipeline`

把批改过的试卷、作业或答题卡照片，变成可复核的错题诊断成果：先看清字迹，再审查题目本身是否成立，接着用多路独立论证核验标准答案，最后输出**家长版三色诊断报告**与**学生版大白话对照本**两份 Word 文档。

适用学段：小学、初中、高中。题目难度、讲解措辞与知识点映射按学段调整。

## 核心能力

- **三色分离识别**：印刷原题（黑）／学生手写（深蓝）／教师批改与答案（红），按题裁切到原生分辨率认字。
- **题面有效性审查**：六维检查 × 五视角交叉论证；题目出错时明确提示，不把题目问题记到学生头上。
- **标准答案交叉论证**：六路独立求解 + 红队反证 + 收敛裁决 + 算术表达式机器验证；答案未收敛时上报待裁定，不强行定案。
- **四维判定与五类错因**：答案／方法／条件／表达四维，A–E 五类错因，复合错因按主次拆分。
- **统一正确率口径**：正确率、覆盖率、答案收敛率三项同时给出；样本不足时不输出百分比。
- **双份 Word 交付**：家长版含判定表、深度诊断、变式答案；学生版含逐步骤双栏对照与「就岔在这一步」红字标记。
- **变式与复习**：换数字／换条件／换情境，配 1/2/4/7/15/30 天艾宾浩斯排期。

## 快速开始

```bash
pip install python-docx
python scripts/build_books.py --data "templates/sample-exam.json" --out "./output/2026-01-01"
```

脚本会输出 `audit checks`、`tri-color missing`、`privacy hits` 与 `RESULT: PASS | files: 2`。任一自检失败时退出码为 1，不交付。

换一套卷子：复制 `templates/sample-exam.json`，按 `references/数据契约.md` 替换 `meta`、汇总表与逐题数据即可，**不需要改渲染代码**。

## 输入数据契约

输入是一个 UTF-8 编码的 JSON 文件（示例：`templates/sample-exam.json`），顶层字段如下。完整字段定义与算术硬约束见 `references/数据契约.md`。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `schema_version` | string | 是 | `1.0` 或 `1.1`；`1.0` 走兼容路径，`1.1` 启用六个核验字段 |
| `meta` | object | 是 | `exam`／`subject`／`grade`／`date`／`full_score`／`score`／`lost`／`wrong_count`／`source`／`privacy_note` |
| `score_rows` | array | 是 | 题型得分汇总表，每行 `[题型, 题号范围, 满分, 得分, 失分, 题数]` |
| `items` | array | 是 | 逐题数据，每题含题号、题型、原题、学生作答、正确答案、判定、错因、诊断、变式等 |

**硬性校验**（脚本执行前会检查，任一不满足退出码为 1）：

- `full_score = score + lost`，且 `lost ≥ 0`；汇总表各题型得分之和与 `score` 一致。
- 每题 `wrong_count` 与 `items` 中被判为失分的题数一致。
- 学生版必须含逐步骤双栏对照（`left` 我当时怎么想的／`right` 正确该怎么想），走岔行用红字加「【就岔在这一步】」。
- v1.1 的六项核验字段（题面三态、答案收敛状态、`machine_verified`、`accuracy_summary` 等）取值必须合法：`INVALID` 题不得进入逐题错题列表，`pending` 题不得计入正确率分母，正确率与覆盖率须同时给出。
- 隐私：任何字段不得出现姓名、班级、学号、学校、考号、座位号；命中即拒绝交付（可用 `--forbidden` 追加禁写词）。

**v1.0 兼容**：旧数据缺核验字段时脚本自动跳过对应章节与自检，输出 `audit checks: SKIPPED (v1.0 data)`，仍生成双份 Word。

## 输出说明

脚本默认在 `./output/<YYYY-MM-DD>/` 下生成两份 Word（可用 `--out` 或环境变量 `CUOTI_OUTPUT_DIR` 覆盖，可用 `--only parent|student|both` 选择单份）：

| 文件 | 面向 | 必含内容 |
|---|---|---|
| `*_家长版三色诊断报告.docx` | 家长 | 判定表（八列）、四张存疑清单、题面三态计数、深度错因诊断、变式题与答案、正确率／覆盖率／收敛率三项、复习排期 |
| `*_学生大白话对照本.docx` | 学生 | 逐步骤双栏对照、「就岔在这一步」红字标记、每题固定小节顺序（这题在考啥→题目→我写的→正确答案→一句话说清→两条路摆一起→记口诀→错因归类→换个数再来两道→课本知识点→怎么练最快） |

**三色约定**：印刷原题黑色、学生手写深蓝、教师批改与答案红色。脚本交付前遍历 `run.font.color.rgb`，确认三色均写入（`tri-color missing: none`），并跑隐私扫描（`privacy hits: none`）。终端输出 `RESULT: PASS | files: 2` 表示全部自检通过。

## 权限与数据说明

- 读取：用户主动提供的试卷图片与结构化 JSON。
- 写入：仅 `--out` 指定目录（默认 `./output/<YYYY-MM-DD>`，可用环境变量 `CUOTI_OUTPUT_DIR` 覆盖），生成两份 `.docx`。
- 不联网、不下载或执行远程代码、不访问系统敏感目录。
- 包内不含任何账号口令或第三方服务标识；运行无需额外配置。
- 产物不含姓名、班级、学号、学校、考号、座位号；家长版称「该生」，学生版用「我」。

## 依赖与兼容

- Python 3.9+；`python-docx`（`build_books.py` / `docx_kit.py`）；`verify_answers.py` 仅用标准库。
- 结构化数据 v1.0 可直接使用；v1.1 的六个核验字段为可选，缺失时脚本自动跳过对应章节与自检。
- 本技能不承诺标准答案 100% 正确：同源错误、超纲题、答案源错误、主观题无唯一解、转写错误属残余风险，详见 `references/答案交叉论证.md`。
